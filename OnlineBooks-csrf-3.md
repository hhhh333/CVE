# In version 1.0.0 of OnlineBooks, there is a CSRF vulnerability in the '/pages/pack/books/BooksSerlet/insertPro' interface. Attackers may use cross site request forgery techniques such as CSRF HTML to trick clients into making unexpected requests to the web server, which will then be treated as a genuine request from the client - thus performing book addition operations as victims, leading to issues such as arbitrary book addition.



**Files:**

`src/cn/ylcto/book/servlet/BooksServlet.java`
