# In the OnlineBooks 1.0.0 version, the '/pages/back/member/member_insert.jsp' interface has a CSRF vulnerability. An attacker may use methods such as cross-site request forgery (CSRF) HTML to trick the client into sending an unexpected request to the web server, and this request will subsequently be treated as a genuine request from the client - thereby executing user entry operations as the victim, leading to issues such as the ability to add arbitrary users and data leakage.



**Files:**

`src/cn/ylcto/book/servlet/MemberServlet.java`
