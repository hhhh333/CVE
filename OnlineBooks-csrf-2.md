# In the OnlineBooks 1.0.0 version, the '/pages/back/member/member_insert.jsp' interface has a CSRF vulnerability. An attacker may use methods such as cross-site request forgery (CSRF) HTML to trick the client into sending an unexpected request to the web server, and this request will subsequently be treated as a genuine request from the client - thereby executing the operation of adding a category under the victim's identity, leading to issues such as the ability to add arbitrary book categories.
